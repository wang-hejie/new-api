### 阶段 3 —— 顶栏按钮与 Home 按钮的"内/外链"识别

- [x] **3.1 新建工具函数 — Done**
      在 `web/src/helpers/` 下新增 `docs.js`，并在 `helpers/index.js` 末尾 `export * from './docs'`，保持已有的统一导出路径：
      ```js
      // 判定 docs 链接是否走内部 SPA 跳转
      export const resolveDocsTarget = (docsLink) => {
        const trimmed = (docsLink || '').trim();
        if (!trimmed) return { kind: 'internal', to: '/docs' };  // 决策 B1
        const isDocsPath = (path) => path === '/docs' || path.startsWith('/docs/');
        if (trimmed.startsWith('/') && isDocsPath(trimmed.split(/[?#]/, 1)[0])) {
          return { kind: 'internal', to: trimmed };
        }
        try {
          const u = new URL(trimmed);
          if (u.origin === window.location.origin && isDocsPath(u.pathname)) {
            return { kind: 'internal', to: u.pathname + u.search + u.hash };
          }
        } catch {}
        return { kind: 'external', href: trimmed };
      };
      ```
      Done summary:
      已新增 `web/src/helpers/docs.js`，实现空值、相对 `/docs`、同源 `/docs` 与外链的目标解析。
