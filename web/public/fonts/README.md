# Docs 字体资产说明

本目录的字体仅供内置 `/docs` 页面使用，由 `web/src/pages/Docs/docs-theme.css` 按需加载，不在全站预加载。

## 来源

- `Inter-*.woff2`
  - 来源包：`@fontsource/inter@5.2.8`
  - 文件来源：`files/inter-latin-{400,500,600,700}-normal.woff2`
  - 上游项目：https://github.com/rsms/inter
  - 许可：SIL Open Font License 1.1

- `JetBrainsMono-*.woff2`
  - 来源包：`@fontsource/jetbrains-mono@5.2.8`
  - 文件来源：`files/jetbrains-mono-latin-{400,500}-normal.woff2`
  - 上游项目：https://github.com/JetBrains/JetBrainsMono
  - 许可：SIL Open Font License 1.1

## 文件映射

- `Inter-Regular.woff2`：Inter Latin 400 normal
- `Inter-Medium.woff2`：Inter Latin 500 normal
- `Inter-SemiBold.woff2`：Inter Latin 600 normal
- `Inter-Bold.woff2`：Inter Latin 700 normal
- `JetBrainsMono-Regular.woff2`：JetBrains Mono Latin 400 normal
- `JetBrainsMono-Medium.woff2`：JetBrains Mono Latin 500 normal

完整字体许可文本可在对应 Fontsource 包与上游仓库中查看；两者均使用 SIL Open Font License 1.1。
